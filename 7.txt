
class Employee {
    int id;
    String name, department;
    int yearsOfService;
    double basicSalary;

    Employee(int id, String name, String department,
             int yearsOfService, double basicSalary) {
        this.id = id;
        this.name = name;
        this.department = department;
        this.yearsOfService = yearsOfService;
        this.basicSalary = basicSalary;
    }

    double calculateSalary() {
        double allowance = basicSalary * 0.20;
        double increment = basicSalary * 0.05 * yearsOfService;

        return basicSalary + allowance + increment;
    }

    void displayDetails() {
        System.out.println("ID: " + id);
        System.out.println("Name: " + name);
        System.out.println("Department: " + department);
        System.out.println("Years of Service: " + yearsOfService);
        System.out.println("Basic Salary: " + basicSalary);
        System.out.println("Calculated Salary: " + calculateSalary());
    }
}

class Developer extends Employee {
    String skill;

    Developer(int id, String name, String department,
              int years, double salary, String skill) {
        super(id, name, department, years, salary);
        this.skill = skill;
    }

    @Override
    double calculateSalary() {
        return super.calculateSalary() + 10000;
    }

    @Override
    void displayDetails() {
        super.displayDetails();
        System.out.println("Skill: " + skill);
    }
}

class Manager extends Employee {
    int teamSize;
    String managementLevel;

    Manager(int id, String name, String department,
            int years, double salary, int teamSize,
            String managementLevel) {
        super(id, name, department, years, salary);
        this.teamSize = teamSize;
        this.managementLevel = managementLevel;
    }

    @Override
    double calculateSalary() {
        return super.calculateSalary() + (teamSize * 1000);
    }

    @Override
    void displayDetails() {
        super.displayDetails();
        System.out.println("Team Size: " + teamSize);
        System.out.println("Management Level: " + managementLevel);
    }
}

public class EmployeeManagement {
    public static void main(String[] args) {

        Employee[] employees = new Employee[3];

        employees[0] = new Employee(
            101, "Amit", "HR", 2, 30000);

        employees[1] = new Developer(
            102, "Rahul", "IT", 3, 40000, "Java");

        employees[2] = new Manager(
            103, "Priya", "Sales", 5, 50000, 4, "Senior");

        for (Employee e : employees) {
            System.out.println("\n--------------------");
            e.displayDetails();
        }
    }
}




## Theory: Employee Management System Using Inheritance in Java

1\. Aim: To develop an Employee Management System using inheritance and method overriding in Java.

2\. Employee Class: The base class stores employee details such as ID, name, department, years of service, and basic salary.

3\. Parameterized Constructor: Initializes employee details when an object is created.

4\. Salary Calculation: The `calculateSalary()` method calculates salary by adding a 20% allowance and a 5% increment for each year of service to the basic salary.

5\. Display Method: The `displayDetails()` method displays employee information and calculated salary.

6\. Inheritance: The `Developer` and `Manager` classes inherit properties and methods from the `Employee` class using the `extends` keyword.

7\. Developer Class: Stores the developer's skill and adds a fixed ₹10,000 to the calculated salary.

8\. Manager Class: Stores team size and management level and adds ₹1,000 per team member to the calculated salary.

9\. `super` Keyword: Calls the parent class constructor and accesses parent class methods.

10\. Method Overriding: The `Developer` and `Manager` classes override the `calculateSalary()` and `displayDetails()` methods.

11\. Polymorphism: An `Employee` reference can refer to `Employee`, `Developer`, and `Manager` objects, allowing the appropriate overridden methods to execute.

12\. Array of Objects: An `Employee` array stores three employee objects of different types.

13\. Enhanced For Loop: Iterates through the employee array and displays each employee's details.

14\. Conclusion: The program demonstrates classes, objects, constructors, inheritance, method overriding, the `super` keyword, and runtime polymorphism in Java.
