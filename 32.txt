
import java.net.*;
import java.io.*;

public class Server {
    public static void main(String[] args) {
        try {
            ServerSocket ss = new ServerSocket(5000);

            System.out.println("Server started...");
            System.out.println("Waiting for client...");

            Socket s = ss.accept();
            System.out.println("Client connected!");

            BufferedReader in = new BufferedReader(
                new InputStreamReader(s.getInputStream()));

            PrintWriter out = new PrintWriter(
                s.getOutputStream(), true);

            String msg = in.readLine();
            System.out.println("Client says: " + msg);

            out.println("Hello Client! Message received.");

            in.close();
            out.close();
            s.close();
            ss.close();

            System.out.println("Server closed.");
        } catch (Exception e) {
            System.out.println(e);
        }
    }
}




import java.net.*;
import java.io.*;

public class Client {
    public static void main(String[] args) {
        try {
            Socket s = new Socket("localhost", 5000);

            BufferedReader in = new BufferedReader(
                new InputStreamReader(s.getInputStream()));

            PrintWriter out = new PrintWriter(
                s.getOutputStream(), true);

            out.println("Hello Server!");

            String reply = in.readLine();
            System.out.println("Server says: " + reply);

            out.close();
            in.close();
            s.close();
        } catch (Exception e) {
            System.out.println(e);
        }
    }
}





## Theory: Client-Server Communication Using Socket Programming in Java

1\. This program demonstrates communication between a client and a server using Java Socket Programming.

2\. The `ServerSocket` class is used on the server side to listen for client connections on port number `5000`.

3\. The `Socket` class establishes a connection between the client and the server.

4\. The `accept()` method waits for a client to connect to the server.

5\. The `getInputStream()` method receives data from the connected socket, while `getOutputStream()` sends data through the socket.

6\. The `InputStreamReader` class converts byte streams into character streams.

7\. The `BufferedReader` class reads text messages using the `readLine()` method.

8\. The `PrintWriter` class sends text messages to the other side using the `println()` method.

9\. The client connects to the server using `new Socket("localhost", 5000)`.

10\. The client sends the message "Hello Server!" to the server.

11\. The server receives and displays the client's message using `readLine()`.

12\. The server sends the reply "Hello Client! Message received." to the client.

13\. The client receives and displays the server's reply.

14\. The `try-catch` block handles exceptions that may occur during network communication.

15\. The `close()` method closes the input stream, output stream, socket, and server socket after communication is completed.

Conclusion: This program demonstrates basic two-way communication between a client and a server using Java's `ServerSocket`, `Socket`, `BufferedReader`, and `PrintWriter` classes.
