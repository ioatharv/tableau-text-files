import java.util.Scanner;

enum Year {
    FY, SY, TY, BTech
}

class Student {
    int prn;
    String name;
    String department;
    Year year;
    String division;
    double percentage;

    // Default constructor
    Student() {
        this(0, "Unknown");
    }

    // Constructor with PRN and name
    Student(int prn, String name) {
        this(prn, name, "CSE", Year.FY, "A", 0.0);
    }

    // Constructor with all attributes
    Student(int prn, String name, String department,
            Year year, String division, double percentage) {
        this.prn = prn;
        this.name = name;
        this.department = department;
        this.year = year;
        this.division = division;
        this.percentage = percentage;
    }

    // Display student details
    public String toString() {
        return prn + "\t" + name + "\t" + department + "\t"
                + year + "\t" + division + "\t" + percentage;
    }
}

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        Student[] students = new Student[5];

        // Accept details of five students
        for (int i = 0; i < students.length; i++) {
            System.out.println("\nEnter details of Student " + (i + 1));

            System.out.print("Enter PRN: ");
            int prn = sc.nextInt();
            sc.nextLine();

            System.out.print("Enter Name: ");
            String name = sc.nextLine();

            System.out.print("Enter Department: ");
            String department = sc.nextLine();

            System.out.print("Enter Year (FY/SY/TY/BTech): ");
            Year year = Year.valueOf(sc.nextLine().trim());

            System.out.print("Enter Division: ");
            String division = sc.nextLine();

            System.out.print("Enter Percentage: ");
            double percentage = sc.nextDouble();
            sc.nextLine();

            students[i] = new Student(
                prn, name, department, year, division, percentage
            );
        }

        // Display all students
        System.out.println("\n--- ALL STUDENT RECORDS ---");
        System.out.println("PRN\tName\tDepartment\tYear\tDivision\tPercentage");

        for (Student s : students) {
            System.out.println(s);
        }

        // Display students of selected year
        System.out.print("\nEnter year to search (FY/SY/TY/BTech): ");
        Year selectedYear = Year.valueOf(sc.nextLine().trim());

        System.out.println("\n--- STUDENTS OF " + selectedYear + " ---");
        boolean found = false;

        for (Student s : students) {
            if (s.year == selectedYear) {
                System.out.println(s);
                found = true;
            }
        }

        if (!found) {
            System.out.println("No student found for this year.");
        }

        // Find student with highest percentage
        Student topper = students[0];

        for (int i = 1; i < students.length; i++) {
            if (students[i].percentage > topper.percentage) {
                topper = students[i];
            }
        }

        System.out.println("\n--- HIGHEST PERCENTAGE ---");
        System.out.println(topper);

        sc.close();
    }
}



## Theory: Student Management System Using Java

1\. Aim: To develop a Student Management System using Java classes, objects, constructors, and arrays.

2\. Enum: The `Year` enum defines four academic years: FY, SY, TY, and BTech.

3\. Student Class: The `Student` class stores PRN, name, department, academic year, division, and percentage.

4\. Data Members: Variables are used to store the details of each student.

5\. Default Constructor: Initializes default values by calling another constructor using `this()`.

6\. Parameterized Constructor: Initializes PRN and name and assigns default values to the remaining attributes.

7\. Constructor with All Attributes: Initializes all student details using the `this` keyword.

8\. Constructor Chaining: The `this()` statement calls another constructor within the same class.

9\. toString() Method: Overrides the `toString()` method to display student details in a readable format.

10\. Array of Objects: A `Student` array stores the records of five students.

11\. Input Using Scanner: The `Scanner` class accepts student details from the user.

12\. Display Records: A `for` loop displays the details of all students.

13\. Year-Wise Search: The program displays students belonging to the academic year selected by the user.

14\. Highest Percentage: The program compares students' percentages and displays the student with the highest percentage.

15\. Conditional Statements: The `if` statement checks the academic year and identifies the student with the highest percentage.

16\. Conclusion: The program demonstrates enums, classes, objects, constructor overloading, constructor chaining, method overriding, arrays of objects, searching, and comparison in Java.
